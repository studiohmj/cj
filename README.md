## 응시 방법

- **전체 모의고사**: 1~5교시를 실제 순서대로 이어서 풉니다. 채점과 해설은 모든 교시를 마친 뒤 한 번에 공개됩니다.
- **교시별 실전**: 원하는 교시 하나만 실제 제한시간으로 풉니다.
- **교시별 연습** (적성검사): 시간 제한 없이 한 문제씩 채점하고 해설과 '빠른 풀이'를 바로 확인합니다.

적성검사는 키보드 `1`~`5`로 답을 고르고 `←` `→`로 문항을 이동할 수 있습니다. 제한시간이 끝나면 자동으로 제출됩니다.

## 결과 분석

- **적성검사**: 영역별 정답 수·정답률·사용 시간, 오답과 미응답 문항의 해설
- **인성검사 Part 1**: 요인별 응답 평균, 응답 분포, 같은 성향을 다르게 물은 문항 사이의 응답 일관성
- **인성검사 Part 2**: 요인마다 출제 횟수가 달라 횟수 대신 비율로 계산한 우선순위 지수((가깝다 − 멀다) ÷ 출제 수)와 먼저 고른 가치·밀어낸 가치 해석
