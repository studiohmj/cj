# CJ CAT·CFT 실전 모의고사

공식 시간표와 같은 5교시 구성의 연습용 모의고사입니다.

| 구분 | 교시 | 영역 | 문항 수 | 시간 |
| --- | --- | --- | --- | --- |
| 적성검사 CAT | 1~4교시 | 언어이해 · 언어추리 · 자료해석 · 창의수리 | 각 20문항 | 각 15분 |
| 인성검사 CFT | 5교시 | Part 1 / Part 2 | 275문항 / 90세트 | 45분 / 15분 |

- 모든 문항은 유형을 참고해 직접 만든 연습 문항이며 실제 기출이 아닙니다.
- 인성검사 분석은 참고용이며 실제 평가 기준과 관계없습니다.
